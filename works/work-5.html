GAME // ORIGINAL IP WORLDVIEW BIBLE VER.01

《熵减旅者》

NEGENTROPY TRAVELER

一个普通女大，穿越无数真实宇宙，用念化解心魔、用战斗斩杀熵魔，治愈“发炎的世界”。 但每治好一个别人，她自己的世界就离消亡更近一步。

  • 原创游戏世界观
  • 无限流穿越
  • 战斗 × 念之双路径
  • 高维不可名状
  • 羁绊与治愈
  • OE 开放式结局

“她治愈的每一个世界，都在向她自己的世界收取代价。”

类型 / GENRE

无限流穿越 · 多世界单元剧 · 世界观驱动

核心体验 / LOOP

进入熵涡世界 → 获得该世界能力套装 → 战斗斩杀熵魔 ／ 以念化解心魔 → 消炎离开

叙事结构 / STRUCTURE

失忆重走 · 记忆拼合 · 终局二选一 · OE 戛然而止

物理层 PHYSICS LAYER

这个世界的魔法，其实是一套可以被观测的物理规则。

自然规律

熵增

每个宇宙都是近乎孤立的系统，熵增不可逆，宇宙终将走向热寂。这是规律，不是灾难。

→
异常加速

熵涡

局部熵增突然加速——如同本该活 80 岁的人中途罹患重病。根源是核心生命体的“念”异常聚集与扭曲。

→
内心扭曲

心魔

执念、怨恨、绝望、遗憾达到临界值，在个体内部形成“念的漩涡”。

→
外溢具象

熵魔

心魔外溢到物质世界的投影，持续加速该宇宙熵增，不干预则万物提前归于虚无。

对抗方向 ↺ 熵减

熵减是生命的奇迹，是顽强生机，代表创造、秩序与意义。它无法逆转熵增，只对抗“不完整的终结”——让该发生的事有机会发生，让宇宙按自己的节奏走完该走的路。

01

熵增

ENTROPY ↑

宇宙自然的、不可逆的老化。所有系统的底色。

02

熵涡

ENTROPY VORTEX

由心魔引发的局部熵增加速，是需要被“消炎”的病灶。

03

念

WILL / NEN

情感、意志、执念、牵挂、羁绊的统称，是一种可观测的物理力场。

04

熵减

NEGENTROPY

生命的奇迹——创造、秩序与意义，是旅者带给世界的东西。

熵魔图鉴 DEMON BESTIARY

熵魔形态因心魔类型而异——你面对的怪物，就是某个人内心的形状。

  • 心魔执念 / 怨恨
    →

    黑色尖刺聚合体

    不断扩张，尖刺所指皆是未解之恨。

  • 心魔绝望 / 悲伤
    →

    灰色雾状生物

    所过之处色彩褪去，世界变成一张褪色的照片。

  • 心魔贪婪 / 权力欲
    →

    无形吞噬之力

    看不见形体，只看见周围的物质不断消失。

  • 心魔恐惧 / 逃避
    →

    扭曲的镜像世界

    不伤人，只让人永远迷失在自己不敢面对的地方。

存在层 EXISTENCE LAYER

天道

不关门的免疫系统

THE WAY

天道不是神，没有意志、目的与偏好，像重力一样自然运行。熵魔让宇宙边界产生短暂裂隙，天道不“派遣”任何人——它只是不关闭那扇门。

子宇宙

每一个都是真实世界

MULTIVERSE

魔法、现实、科幻、原始、规则扭曲的世界……各有时间线、物理法则与文明。不是幻境，不是游戏，她认识的每一个人都是真实的生命。

旅者

被裂隙吸引的人

TRAVELER

天道免疫机制自然孕育的存在，多为感知力、同理心或意志力较强者。如水往低处流，被裂隙吸引，嵌入合法身份，执行“消炎”。

旅者的三条铁则 / TRAVELER LIMITS

  1. 01不能同时执行两个任务
  2. 02每次穿越都消耗本体宇宙的“熵值余额”
  3. 03连续穿越会加速本体宇宙的熵增

消炎：两条路径 DUAL PATHS

两条路径并行且独立，完成至少一条即可阻止熵涡恶化；两条都完成，世界被彻底治愈。

PATH A · 战斗路径

物理上消灭熵魔

使用该世界获得的能力与装备正面战斗，斩断病灶。

手段：剑与魔法 / 科技装备 / 一切世界本地力量体系

×
或

PATH B · 念之路径

根本上化解心魔

建立羁绊、理解、陪伴，让扭曲的念归位——病好了，症状自然消失。

手段：信任 / 陪伴 / 看见对方

6 成爽快型 · 直接击杀熵魔
3 成混合型 · 边战斗边理解
1 成治愈型 · 以念化解心魔

能力套装 / LOADOUT

每换一个世界，重开一套 build

  • 每到新世界，自动获得该世界的基础能力体系：魔法、仙术、科技装备……
  • 这些能力只在该世界内生效，带不走。
  • 真正可以跨世界积累的，是战斗经验、判断力与应变能力。
  • 女主不靠“念”战斗——念是熵减的能源，不是战斗的燃料。

死亡规则 / DEATH RULES

死亡不是终点，但有些死亡是

  • 在异世界被杀死意识弹回本体，本体苏醒
  • 异世界任务失败其他旅者接手，自己承受“穿越创伤”
  • 本体宇宙熵值归零宇宙消亡，所有生命真正死亡
  • 本体宇宙执行任务时死亡本体宇宙熵增加速 → 走向消亡

高维层 HIGHER DIMENSION

不可名状的存在

他们是什么，开放给观众想象

高维生物的形态、思考方式全部不作解释——三维生命无法理解他们。但熵增贯穿所有维度，高维本身也在不可逆地老化。他们比三维生命更早感知到这个结局，也因此开始寻找解药。

行为：引导

不操控天道，只在裂隙里嵌入信号

裂隙由熵涡自然产生，旅者被裂隙吸引——这是天道的范畴。高维生物在裂隙中嵌入一道额外信号，不改变裂隙本身，却让靠近的旅者感到更强的“方向感”：直觉、梦境、说不清的牵引。他们需要她走到更远的位置，但她必须自己走到那里，并且自己选择。

与梦境

接管结构层，循循善诱

女主意识受损、同伴搭建梦境时，高维生物以不可名状的方式接管了梦境的结构层：微调她该遇到谁、何时遇到、产生什么羁绊。她在梦中的每一步都在他们视野之内。但他们无法直接让她升维——只能让她走到重新面对邀请的位置。

角色层 CHARACTER LAYER

女主 PROTAGONIST

表层身份

普通女大

有烦恼、有迷茫、有家人朋友——观众可以通过她看到自己。

深层身份

穿越无数世界的旅者

见证不同文明的兴衰，与无数人建立羁绊，承受无数次失去；也是旅者互助组织公认的领袖。

真实身份

拒绝升维的存在

她曾触及真相，面对升维邀请——可以脱离三维成为更高维度的存在。但她拒绝了。

三维世界的一切都在“有限”中发生。时间有限，相遇有限，生命有限。 但所有好的东西——信任、陪伴、善意、创造、一个人对另一个人的在乎—— 都是从这些限制里长出来的。她见过的每一个值得记住的瞬间，都发生在“有限”之中。

她后来意识到，她一直在做的事情本身就是一种熵减：在熵增主宰的宇宙中， 见证并参与那些短暂却真实的东西。高维邀请她离开这些限制。 但她认为，她的位置不在这里（那里）。

—— 她拒绝升维，不是不懂高维的价值，而是已经知道自己选择什么了。

现状 / CURRENT STATE

意识受损，陷入近似植物人的状态。同伴们将她过去的真实经历编码为“记忆梦境”，让她重新经历自己走过的路；高维生物接管了梦境结构层。她正在梦境中重新确认自己是谁。

同伴 / COMPANIONS

和她一样的人类旅者

同伴们来自不同宇宙，在穿越中感受过“引导信号”，隐约知道自己并非完全靠自己走到今天；但他们没有被邀请过升维，甚至不知道“升维”是一个选项。

  • 旅者每次穿越都留下心理创伤，积久成心魔；旅者心魔引发的熵涡远比普通人的强大。
  • 女主是走得最远的一个，回三维后组建了旅者互助组织。
  • 他们相信她，不是因为她强大，而是因为她的“有限”里有一种让人愿意跟随的东西。

梦境搭建 / DREAM CRAFT

她走过的世界，都成了修复她的基石

同伴们从她穿越过的文明中“就地取材”，整合拼接成梦境框架：

  • 科幻世界神经映射
  • 修真世界神识修复
  • 奇幻世界灵魂编织

但梦境不完全由同伴掌控——高维生物在框架内部叠加了自己的控制层。

成长线 GROWTH ARC

  1. 初期

    “为什么是我？”

    被迫穿越，只想回家。

  2. 中期

    “我能理解他们了。”

    开始主动感受每一个世界里的人。

  3. 成熟

    “那我来吧。”

    从被征召，变成我愿意承担。

  4. 面对升维

    “我选择留下。”

    主动拒绝高维的邀请。

  5. 复健

    “我好像……做过这些事？”

    在梦境中重新确认自己。

  6. 终局

    “这就是我。”

    重新确认自己的选择。

故事主线 MAIN STORYLINE

女主在失忆状态下，于梦境中重新经历自己作为旅者曾走过的所有世界。每完成一个世界，恢复一段记忆。 所有记忆拼合后，她将重新面对当初那个决定——拒绝升维。 这一次，她必须做出同样的选择，否则肉身消亡，同伴永远失去她。

  1. STAGE 01

    失忆穿越

    她以普通女大身份醒来，被“系统”引导穿越不同世界“消炎”，以为这只是任务，不知道自己正在重走过去的真实经历。

  2. STAGE 02

    羁绊与怀疑

    她在每个世界建立羁绊、击杀熵魔或化解心魔。“熟悉感”逐渐出现——见过的人、听过的话、莫名的直觉。记忆碎片开始苏醒。

  3. STAGE 03

    真相浮现

    记忆拼合，她想起自己曾是走遍无数世界的旅者，触及过宇宙真相，面对过升维邀请。高维生物开始介入梦境，引导她走向终点。

  4. STAGE 04

    最终选择

    她回到当初做出决定的世界，高维生物再次发出邀请。同伴在梦境外部等待，无法干预。故事在她做出选择的瞬间戛然而止。

核心悬念 / OPEN QUESTIONS

  • 她当初为什么拒绝升维？
  • 高维生物究竟想从她身上得到什么？
  • 这一次，她还会做出同样的选择吗？

叙事层 NARRATIVE LAYER

女主

有限的生命才有意义，熵减本身就是价值。

“我不需要升维。无论理由是什么，答案都不会变。”

高维生物

升维是更高维度的运行逻辑；她的效能可适配高维需求。

发出中立引导信号，在梦境中循循善诱。

同伴

尊重女主的选择。

“我们接受你的决定，但请你让自己回来。”

CORE RULE · 核心规则

她的“身份”由这个选择定义

梦境中，女主必须再次做出和当初一样的选择——拒绝升维。 如果她在梦境中选择升维，意味着“当初拒绝升维的她”已经死了： 三维肉身消亡，同伴永远失去她。改变选择，就是改变她自己。

OE · OPEN ENDING

故事在选择发生的那一刻结束

没有交代她选了哪个。观众会带着问题离开——她背叛了自己，还是忠于了自己？
