《维瑞蒂》

VERITY

几千年后的完全科技智能时代，安全局用杀伤性机器人追捕罪犯。刑警之女维瑞蒂在父母被污名处刑后， 以“乔伊·索伦”的身份活下去，最终带着母亲留给她的 114 机器人，夺回真相与自己的名字。

世界观概述 WORLDVIEW

故事发生在几千年后的完全科技智能时代。城市中心高楼林立，悬浮车穿梭，机器人随处可见。 部分犯罪集团掌握尖端技术，能力可与政府抗衡。安全局因此研发具有杀伤性的独特型号机器人， 配属给特别行动队刑警，用于追捕罪犯。

故事主线 STORYLINE

  1. BEAT 01 · 承诺

    维瑞蒂的父母是特别行动队刑警，她从小崇拜英雄。母亲送给她 114 机器人时曾承诺：等她成年， 就告诉她格式化密码，让她完全拥有这台机器；但前提是，她必须训练到足以驾驭它。

  2. BEAT 02 · 中断

    10 岁那年，家遭爆破，父母被当场处刑，新闻称他们畏罪潜逃、非法运输和改造国家武器。 维瑞蒂被 114 带走，由父母旧识杰收养，改名“乔伊·索伦”。

  3. BEAT 03 · 蛰伏

    18 岁时，她意外救下戴眼镜青年，被卷入十一年前的权斗之争：现任安全局局长安东尼奥勾结黑势力上位， 父母与肯特先生都是被陷害的一方。

  4. BEAT 04 · 成年礼

    最终，维瑞蒂以自己为诱饵闯入安全局，输入母亲留下的格式化密码，让 114 格式化，揭露安东尼奥， 为父母恢复清白。这一刻不只是复仇，也是她迟到的成年礼。

角色概念设计 CHARACTER FILES

01 / CV-01

维瑞蒂 / 乔伊·索伦

  • 定位核心主角 / 双身份
  • 身份刑警之女 → 被通缉者的后代 → 改名乔伊·索伦 → 最终夺回“维瑞蒂·贾斯蒂斯”
  • 英雄崇拜
  • 特训痕迹
  • 孤僻
  • 拳套
  • 沙包
  • 堕落感
  • 复仇与自我厌弃

叙事功能

她是观众进入世界观的入口，也是“英雄叙事”被颠覆的载体。

概念文案

维瑞蒂的设计核心是“同一个人的两种名字”。童年维瑞蒂带有英雄崇拜的明亮感， 服装和姿态偏利落、行动导向；成为乔伊后，外形逐渐收敛、冷感、带一点街头和逃避气质。 拳套与沙包是她与过去唯一的连接物。

母亲曾承诺，等她成年，就告诉她 114 的格式化密码，让她真正成为 114 的主人，但前提是， 她必须先训练到足以驾驭它。10 岁那年，承诺随父母之死中断。18 岁，她本应迎来成年礼， 却只能以乔伊·索伦的身份活下去。最终她闯入安全局，输入母亲留下的密码—— 那不是简单的复仇，而是一场迟到的成年礼。

02 / CV-02

114 / UNIT-114

  • 定位机械人外 / 守护型杀伤性机器人 / 母亲的遗物
  • 身份安全局独特型号机器人，经乔伊斯改造；原属维瑞蒂母亲，只听母亲指令
  • 隐身功能
  • 金属质感
  • 幽灵感
  • 沉默
  • 保护即束缚

叙事功能

它是父母“犯罪”的铁证，也是维瑞蒂唯一的保护者；她厌恶它，又只能依赖它。

概念文案

114 的设计核心是“幽灵般的守护者”。它不主动说话，不听从维瑞蒂的命令， 却总在她受伤或危险时突然出现。造型上强调独特金属质感、非人轮廓与隐身状态下的虚化感。

母亲曾计划在维瑞蒂成年时交出格式化密码，让她完全拥有 114。但母亲死后， 114 仍执行“保护维瑞蒂”的旧指令，既保护她，也束缚她。格式化密码因此成为母女之间未完成的约定， 也是维瑞蒂从“被保护者”变成“驾驭者”的关键。对维瑞蒂来说，114 是窒息的存在， 也是她最终反击的唯一底牌。

03 / CV-03

安东尼奥 / ANTONIO

  • 定位主要反派 / 现任安全局局长 / 权斗赢家
  • 身份原分局长，勾结黑势力贩卖技术与武器，陷害肯特与贾斯蒂斯夫妇，最终晋升总局长
  • 地中海大叔
  • 公开演讲
  • 体面权威
  • 虚伪
  • 权力感
  • 被吓破胆的反差

叙事功能

他是“正义机构”腐烂的核心，也是维瑞蒂复仇的直接对象。

概念文案

安东尼奥的设计核心是“体面的恶”。他出现在电视演讲里，是公众眼中的安全局代表； 实际上他靠黑势力支持上位。造型上保留地中海大叔的辨识特征，但用制服、徽章、全息讲台等元素 建立权威感。最终在安全局中心被维瑞蒂逼到吓破胆，是角色设计里最重要的反差时刻。

04 / CV-04

肯特先生 / MR. KENT

  • 定位幕后布局者 / 旧安全局势力 / 维瑞蒂的盟友
  • 身份安东尼奥的死对头，被陷害入狱，最终被无罪释放并重回安全局总局长之位
  • 两鬓斑白
  • 老人
  • 沉稳
  • 旧时代权威
  • 忍辱负重
  • 重整旗鼓

叙事功能

他代表“另一种正义秩序”，也是维瑞蒂父母当年私下联系的人。

概念文案

肯特先生的设计核心是“被压下去的旧秩序”。他两鬓斑白，经历过入狱与失势， 但仍是许多旧部愿意追随的人。造型上以沉稳剪影、克制机械细节和旧式安全局元素为主， 与安东尼奥的“光鲜权威”形成对比。他不是热血领袖，而是一个等待时机的老人。

设计说明 DESIGN NOTE

本项目为初版概念设计，重点不在成片，而在世界观与角色概念。四个角色分别承担不同的视觉与叙事功能： 维瑞蒂是双身份主角，114 是机械人外与情感矛盾，安东尼奥是权力腐败的具象化，肯特先生是旧秩序的回归。 通过轮廓、材质、配色和机械细节的差异，建立同一世界观下的角色识别系统。

01轮廓对比：锐角 × 沉稳剪影
02材质：金属 / 织物 / 烟与虚化
03配色：冷金属蓝 × 警示红 × 黑白
04机械结构：义体细节 × 旧式装备
